# 从 MoBA 门控架构到 CSA2 数字索引器

本项目参考王瑞泰《面向 MoBA 算法门控运算的存算一体异构芯粒系统设计》的门控和片上复用思想，重新实现数字数据通路。可获得材料是原论文 PDF；未获得可确认为作者交付的完整 RTL、SRAM 宏、约束及综合报告。因此这里是**依据论文结构重构新电路**，不是在作者已交付 RTL 上打补丁，也不声称独立重现原论文性能。

原 PDF 共 115 页，SHA-256 `f7a130aa333d57d1ba99cdb72782b1cd324c3d3e5317b63538dce95be16b5490`。下列页码是正文印刷页，PDF 页序号为正文页码 +14。原 PDF 不随本仓库再次分发。

## 原设计与新电路的对应关系

| 组成 | 原论文描述 | 新实现 |
|---|---|---|
| 算法对象 | MoBA，Llama3.1-8B，32 个块选12；主要评估 prefill / TTFT | CSA2 的投影后索引/选择算子，32头×128维，K≤512 |
| 数据准备 | BF16 均值池化形成 Kmean，p30–34 | 外部提供学习投影、归一化/位置变换和量化后的 FP4 index K；禁止用均值替代 |
| 点积组织 | 128 Block×32 Cell；每 Cell 存32×16bit，p29–38 | 16 路 E2M1 小整数乘积，四个32维组，依次计算32头 |
| 数据复用 | GQA=4 导致 Kmean 复制四份，p48 | 每个 K 记录只从在线存储读取一次，在所有索引头间复用 |
| 非线性 | 每头块分数直接参与选择 | 完整128维dot→ReLU→有符号head weight→跨头sum；顺序不能交换 |
| 数值实现 | SRAM-CIM浮点Cell及FP32规约，宏为黑盒，p38/46 | 标准可综合数字 RTL；FP4分组scale、FP32 RNE与渐进下溢可逐bit检查 |
| Top-K | 32行、32级组合位竞争；每拍选一胜者，Top12约12拍，p39–45 | 有界min-heap，每次插入/替换O(logK)，相同分数优先小index；最终位置排序 |
| 请求生命周期 | K/Q 分阶段；论文平台用离线GPU profile与Python时间线，p78–83 | MMIO提交、主动DMA、硬件计算、结果写响应、主机回读；时序在线反馈 |
| 内存与互连 | 论文自建层级网络与共享显存方案，p53–67 | 继承原仓库原生AXI256→AXI2Flit→UCIe→在线mem_sim，三处理源保留 |
| 物理证据 | 数字外围SMIC28综合+文献宏PPA，7nm归一化，p46/79 | 当前实际数字电路的综合报告单列；不借用宏功耗、不做工艺缩放 |

原文的“位串行”选择是**一个周期内沿bit级联**，不能误读成每个bit一个周期。原设计也不是只有一个通信路由器：第四章确有多层通信和规约结构。新工程的差异在于算法数据通路、选取规模、显式生命周期及接入现有在线系统，而不是否定原论文已完成的工作。

## 算术和存储组织

输入Q每头70B有效载荷：64B packed FP4、4B E8M0 scales、2B BF16 weight；AXI记录补齐到96B。K同样补齐96B，有效68B。一个完整32头Q集合的有效载荷为2240B，DMA实际读3072B。一个K向量缓冲保存68B，所有头复用它，避免按头读取32份K。padding算入实际访存，不能把68B载荷当成68B总线传输。

E2M1乘2变成整数集合 `0,±1,±2,±3,±4,±6,±8,±12`。一个32维组的整数量化点积范围为±4608。硬件先精确计算此整数，再乘 `2^(eq+ek-256)` 并舍入为FP32。四组按序累加后做ReLU，乘有符号weight，再在32头间归约。负权重合法，不能以“后续贡献总非负”为假设提前剪枝。

min-heap根存当前最差候选；每个节点64bit，包含score和index。K=512时heap逻辑载荷4KiB；wrapper另有4KiB结果缓存，供位置排序和Reuse。Q缓冲、K缓冲、heap和结果缓存是RTL数组，综合是否映射成触发器或SRAM必须看实际报告。这里没有存储阵列内部乘加，故使用“数字近存计算”一词。

## 接到系统里意味着什么

存储侧原先的 `AouTarget` 输出整burst FIFO对象，并没有现成的RTL AXI引脚。本项目增加协议适配层：MMIO对象逐拍驱动真实AXI256 slave；RTL DMA的AXI256 master再逐拍转换为在线mem_sim请求。普通CPU/GPU/NPU访存保留旁路。所有地址、数据、写mask与响应来自同一个后端镜像。

适配器本身不是可综合总线桥；它属于系统验证环境。可综合边界是 `sparse_gate_axi` 顶层及内部核心/DMA。Verilator仅生成这些RTL的执行模型。其时间由gem5原生SystemC事件轴驱动，不启动第二套SystemC，也不在C++里瞬间计算整个任务。

内部DMA使用单个在途32B请求。这是清晰、可验证的首版吞吐约束；没有假装多通道内存理论带宽已经利用。一次有效选择的结果写与KV gather写都收齐成功BRESP后，才提交DONE。错误任务可能已有部分写入，但不允许软件把部分结果当成功结果消费。

## 可以支持的贡献与仍需研究的内容

当前可支持的工程贡献是一个端口、数值、来源、调度和响应闭合的参考实现：真实低精度门控计算、共享K读、较大K的串行堆选择、候选地址的真实跳读、有限版本缓存，以及三处理源统一系统中的在线反馈。CSA2的跨层复用、分层候选与低精度格式来自已有算法，不能列成本项目发明。

是否达到学术上的架构创新，需要与同等精度/资源的其他MAC布局、选择器、SRAM组织和内存调度做受控比较。不能仅根据“换了近期算法”宣称顶会级新意，也不能把已有稀疏算法相对于dense attention的收益归给本电路。相应论文只报告实际实现与实测支持的结论。

下一步有明确硬件价值的方向是：Q字节装载宽化、多token并行、K双缓冲、计算和堆更新重叠、带资源约束的多在途DMA、可推断SRAM接口、保持当前数值合同的浮点归约流水。每项优化须同时报告面积、时序、真实memsim事务与系统完成时间，保留没有收益的情况。
