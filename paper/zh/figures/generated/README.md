# 中文概念图

四张 PNG 由内置 `image_gen` 工具编辑英文原图生成。初版调用 4 次；本次为系统图再调用 1 次，将门控命令发送端明确改为 Vortex CP DMA。累计 **5 次**调用，均成功；当前四张图各有一个选用版本。英文系统图也同步更新。

所有选用 PNG 均已实际打开，检查中文可读性、结构、箭头及下列数值。工具产物仅按字节复制，未使用 Python/PIL 绘制或修改位图，也未裁剪、重采样、重新编码。这些图用于解释架构和协议，不是电路原理图、仿真波形或测量结果，不新增实验数据。
